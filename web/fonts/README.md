# Fonts

Words are set in Mona Sans; headlines use the same file at a wider, heavier cut. Numbers, labels and
everything measured are set in Monaspace Neon. Unbounded is only for the opening-soon page
(`site/soon.css`). All three are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org); the licence texts for Mona Sans and Monaspace sit beside the files,
which are the Latin sets as published, not re-cut or renamed.
