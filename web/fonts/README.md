# Fonts

Words are set in Mona Sans; headlines use the same file at a wider, heavier cut. Numbers, labels and
everything measured are set in Monaspace Neon; the opening-soon page (`site/soon.css`) uses Mona Sans
too. Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org); the licence texts sit beside the files,
which are the Latin sets as published, not re-cut or renamed.
